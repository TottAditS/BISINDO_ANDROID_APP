# Toolchain requirements -- BISINDO_ANDROID_APP
# Checklist alat yang harus terpasang di mesin sebelum scaffold/build project ini.
# Bukan pip requirements (project ini Kotlin/Android, bukan Python) -- tetap dinamai .txt
# supaya jadi checklist plain-text yang gampang dicentang manual.
# Status mesin saat ini (dicek 2026-07-31): SEMUA item di bawah BELUM terpasang.

[x] JDK 17
    - Package: Eclipse Temurin JDK 17 (EclipseAdoptium.Temurin.17.JDK), versi 17.0.20.8
    - Install: winget install --id EclipseAdoptium.Temurin.17.JDK -e
    - Verifikasi: java -version
    - Terpasang di: C:\Program Files\Eclipse Adoptium\jdk-17.0.20.8-hotspot\ (JAVA_HOME sudah di-set otomatis)

[x] Gradle 8.13 (binary-only, dipakai sekali untuk bootstrap wrapper)
    - Source: https://gradle.org/releases/ -> "Binary-only" zip, versi 8.13
    - Install: extract ke C:\gradle\gradle-8.13, tambahkan C:\gradle\gradle-8.13\bin ke PATH
    - Verifikasi: gradle -v
    - Catatan: setelah project di-scaffold dan gradlew di-generate (langkah 9 di README), Gradle
      standalone ini tidak dipakai lagi -- build selanjutnya selalu lewat .\gradlew.bat
    - Terpasang di: C:\gradle\gradle-8.13 (User PATH sudah ditambahkan)

[x] Android SDK "Command line tools only"
    - Source: https://developer.android.com/studio#command-line-tools-only (Windows), build 15859902
    - Install: extract, pindahkan folder cmdline-tools dari dalam zip ke
      <sdk_root>\cmdline-tools\latest\
    - Env var: set ANDROID_HOME (atau ANDROID_SDK_ROOT) ke <sdk_root>; tambahkan
      <sdk_root>\cmdline-tools\latest\bin dan <sdk_root>\platform-tools ke PATH
    - Verifikasi: where sdkmanager, where adb
    - Terpasang di: C:\Android\sdk (ANDROID_HOME + ANDROID_SDK_ROOT sudah di-set, User PATH sudah
      ditambahkan). SHA256 zip diverifikasi cocok dengan yang resmi.
    - Catatan lingkungan: sdkmanager.bat internal manggil `findstr`/`where` tanpa full path, dan di
      mesin ini cmd.exe gagal resolve nama bare itu (padahal file-nya ada & valid via full path).
      Workaround dipakai: (1) tulis manual file hash lisensi ke <sdk_root>\licenses\ (skip
      `sdkmanager --licenses` interaktif), (2) set env var SKIP_JDK_VERSION_CHECK=true saat panggil
      sdkmanager (skip internal java-version check yang gagal parsing karena findstr broken).
      Kalau nanti sdkmanager dipanggil lagi manual dari terminal biasa (bukan lewat Claude), mungkin
      perlu env var yang sama kalau problem cmd/findstr ini juga muncul di sana.

[x] SDK components (via sdkmanager, setelah cmdline-tools terpasang)
    - sdkmanager --licenses   (terima semua) -> diganti workaround manual, lihat catatan di atas
    - sdkmanager "platform-tools" "platforms;android-35" "build-tools;35.0.0"
    - Verifikasi: adb --version; ls <sdk_root>\platforms; ls <sdk_root>\build-tools
    - Hasil verifikasi: adb 1.0.41 (platform-tools 37.0.1), platforms\android-35 ada,
      build-tools\35.0.0 ada.
